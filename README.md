# Hello-C

A personal project documenting my journey learning the C programming language from the fundamentals toward embedded software engineering.

## Goals

- Learn modern C (C17)
- Build strong programming fundamentals
- Develop professional Git and GitHub habits
- Prepare for embedded software engineering projects

## Development Environment

- macOS
- Clang
- Visual Studio Code
- Git & GitHub
- Make

## Project Structure

hello-c/
├── build/          # Compiled executables (ignored by Git)
├── include/        # Header files (future lessons)
├── lessons/        # Completed lesson source files
├── src/            # Current working program
├── Makefile
└── README.md
